# Toms Johnson — Graphic & Motion Graphic Designer Portfolio & CV (Next.js)

A custom **Next.js + TypeScript + Tailwind CSS** portfolio and interactive resume web application built for **Toms Johnson** (*Graphic & Motion Graphic Designer*, Andheri East, Mumbai).

## Aesthetic & Features

- **Warm Bronze, Cream & Charcoal Palette**: Directly inspired by Toms Johnson's original curriculum vitae (`#1C1917` Charcoal, `#9E7B56` Warm Bronze, `#DDBEA0` Pale Gold, and `#FAF8F5` Editorial Cream).
- **Interactive Motion Comp Previewer**: A live keyframe & 60 FPS motion showcase demonstrating Toms's work across kinetic typography, event branding, and social media reels.
- **Filterable Selected Works & Case Studies**: Showcasing projects for **Zilicon Network Solution**, **Knot with Style**, **Vama**, and digital brand campaigns with interactive case study modals, color palettes, deliverables, and tool stacks.
- **Core Skills & Additional Strengths Bento Grid**:
  - **7 Core Skills**: Graphic Design, Motion Graphics, Branding & Visual Identity, Social Media Creatives, Event Design, Visual Storytelling, Layout & Typography.
  - **5 Additional Strengths**: Creative thinking, Attention to detail, Adaptability, Visual problem-solving, Collaboration.
  - **Languages**: English & Malayalam.
- **Faithful Two-Column Interactive CV Replica (`#cv-sheet`)**:
  - Switch seamlessly between the **Live HTML/CSS Web Replica** and the **Original Uploaded CV Scan** (`/toms-johnson-cv.jpg`).
  - Includes a print-optimized stylesheet (`window.print()`) for instant PDF export.

## Getting Started

1. Ensure [Node.js](https://nodejs.org/) (v18.18+ or v20+ LTS) is installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
